# PropHover web app

Next.js App Router + TypeScript app for the PropHover course project.

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — the home page should show **PropHover**.

```bash
npm run build
npm run lint
```
